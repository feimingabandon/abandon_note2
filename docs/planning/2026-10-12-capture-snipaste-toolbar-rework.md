# 截图工具栏按 Snipaste 结构重做

本方案替代当天上一版的分裂式工具菜单与独立参数浮层。用户指出下拉三角难点、箭头入口过深、圆角外出现黑边，并要求以 Snipaste 免费版为工具栏与交互参考。

## 对照依据

- 仓库已记录对标软件为 Snipaste 免费版商店版 2.11.3。
- 本轮查看 [Snipaste 官网](https://www.snipaste.com/) 的官方 [标注示例](https://i.v2ex.co/746553IP.png)。示例中，矩形、椭圆、箭头、画笔等是一级按钮；当前工具的笔宽、颜色和效果等出现在下方二级参数栏。
- 官网示例是历史示意图，不能据此声称完成本机 2.11.3 的逐像素对照。本机 Computer Use 未返回 Snipaste 窗口，启动授权超时；不修改对标软件配置。

## 修改

1. 取消工具的分裂式按钮与狭窄三角点击区。矩形、椭圆、箭头、直线、画笔、荧光笔、文字、马赛克、橡皮擦均直接可点；箭头始终是独立入口。
2. 工具按钮至少 32×30 逻辑像素，完整矩形响应点击。点击后恢复画布焦点，可立即绘制；保持现有工具参数记忆与绘图能力。
3. 当前工具的参数自动出现在工具栏下方。取消额外“参数”按钮和阻断绘制的参数弹窗；选择工具后第一次画布拖动即绘制。
4. 数字和字体保持输入焦点；Enter/Escape 从参数输入返回画布。输入法组合期间的 Escape/Enter 只处理组合状态，不向截图退出或完成动作传播。
5. 窄空间优先把输出操作分行，保持箭头可达；参数内容超出时允许内部横向滚动，不把字段塞入难找的溢出菜单。
6. 工具栏和更多菜单使用一致的 4px 小圆角。主工具栏只保留一套绘制，Windows 实际窗口区域与圆角同步裁切，独立工具窗使用透明背景；避免只绘制圆角表面、矩形窗口四角仍覆盖底图。
7. 快速截图复制、托盘提醒、连续马赛克和圆形擦除保留本轮已授权的行为。

## 验证边界

仅运行截图 UI、UX、参数持久化的直接专项及必要构建；不扩大到全项目回归。

验证完整按钮边缘点击、箭头直接绘制、就地参数输入和绘制连续性；检查纯白、纯黑、复杂底图，以及截图内子控件和贴图独立工具窗的四角实际合成像素。

Windows 桌面锁定会阻塞焦点与真实屏幕像素验证，必须明确记录，不能将被跳过或未完成的业务断言记为通过。
