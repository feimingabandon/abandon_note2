- 截图发现窄设置页头部挤占正文、侧栏与月历标题叠层、壁纸模糊滑块横向溢出，已修复并截图复查。

请使用从当前源码启动的开发/预览版本。此次没有打安装包，已经安装的旧版本不会因为源码修改自动更新。以下按整轮 UI 改造列出可体验内容；用临时便签或模板操作即可。

| 顺序 | 你可以怎样操作 | 应能感受到的变化 |
| --- | --- | --- |
| 1. 字号稳定 | 保持当前字号，把列表窗口从约 720px 拉到 480px，再拉到 240–360px。 | 文字不再随窗口宽度忽大忽小；变化的是控件排列、换行和内容滚动。 |
| 2. 整体缩放 | 设置中搜索“界面缩放”，依次选择 90%、100%、110%、125%、150%，再点“恢复 100%”；切换列表/月/周，或重启开发版。 | 主界面的文字、图标和控件按比例缩放，所选比例跨视图保存；各视图原字号仍独立。 |
| 3. 标题栏修复 | 界面缩放与“导航图标大小”都设为 150%，将窗口收窄到约 240–360px，分别体验 Apple/Microsoft 标题栏；用鼠标点击设置、帮助。 | 按钮组空间不足时换行，标题栏随内容增高，按钮不会压到正文下方；恢复宽窗后回到单行高度。 |
| 4. 字号预设修复 | 在较矮的窗口里打开设置中的字号预设菜单，再把窗口拉高；关闭后再次打开。 | 原先需要滚动的菜单在空间足够时重新显示完整预设，不再卡住旧高度。 |
| 5. 每年日期修复 | 打开循环模板的新建/编辑，频率选择“每年”，点击“选择日期”；把窗口拉矮，选择日期后在浮层内部滚到下方。 | 日期面板内部可滚动，确认、取消都能真正点到；关闭后焦点回到选择日期入口。 |
| 6. 浮层统一 | 比较设置中的下拉、便签生效日期时间、模板时间/日期范围、标签和天气地区选择器；在窗口边缘打开并滚动页面。 | 面板继承所在区域的字号，靠边时避让/翻转；空间不足时内部滚动；触发器完全滚出可见区域后面板收起。 |
| 7. 动画 | 对同一个下拉快速展开、收起、再展开；比较上下不同展开方向。 | 菜单以淡入淡出和轻微位移出现，约 180ms 进入、140ms 退出；中途反向连续，文字不会被缩放拉伸。设置面板使用统一进出节奏。 |
| 8. 键盘 | 用 Tab 移到选择器，方向键移动选项，Enter 确认、Escape 返回；在日期网格尝试方向键和 Home/End。 | 焦点有可见轮廓；单选菜单退出后接回表单 Tab 顺序，对话式选择器在内部管理焦点。不同控件仍保留各自单选/多选规则。 |
| 9. 按钮与开关 | 对比新建、编辑、月历新建、循环模板和时间选择器的保存/确认按钮；用 Tab 聚焦“置顶”等开关并按空格。 | 主按钮使用稳定蓝底白字，危险操作使用红色配对前景；按钮禁用、加载及按压反馈一致。开关采用实心滑块，设置里是紧凑变体。 |
| 10. 窄窗设置与表单 | 在 125% 或 150% 下缩窄设置、新建或编辑界面，查看壁纸模糊、快捷键及底部操作。 | 设置标签和控件能分行，保存/取消区允许换行；设置保留局部紧凑字号，正文继续内部滚动。 |
| 11. 月历/周历 | 打开日期侧栏，收窄窗口，再放宽；尝试水平滚动日历画布，打开顶部年月/日期选择。 | 保留七天列和可读最小画布，横向滚动限制在日历内；窄窗侧栏覆盖日历。年月浮层避让边缘，点击外部收起时不误点底下日期格。 |
| 12. 右键菜单 | 分别右键列表便签、搜索结果、月周日期格/便签条，悬停普通操作和删除操作，并使用方向键、Escape。 | 三类菜单使用同一行高、材质、阴影、进出动画和选项高亮；删除有明确危险色；菜单内部滚动不会直接把自己关掉。 |
| 13. 主题与提醒 | 切换白底深字、黑底浅字或壁纸后打开上述浮层；如要体验提醒，可建一条 3 分钟后生效且启用软件弹窗的临时便签。提醒出现后更改界面缩放。 | 菜单使用不透明阅读表面，底层文字不再透出来；主按钮前景不跟随正文色而变得难读，提醒窗口同步缩放。 |

范围说明：帮助、更新、日志和软件通知通过公共字号、按钮或模态壳继承相应调整，并非全部重新设计。桌面便签正文字号、灵动岛正文字号和 Qt 截图坐标保留独立语义，本轮未重写原生截图工具。筛选按钮取消“三圈旋转”的改动已存在于基线，不计为本轮新增。
