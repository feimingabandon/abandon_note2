# 截图双屏测试包验收单

用途：后续本地测试安装包提供给有双屏的用户时使用。本文件不是正式版发布或双屏通过声明；当前开发机没有双屏硬件。

## 发包前

- 使用经过本次截图专项验证的源码与原生组件，生成本地 Windows 测试包，构建参数保留 `--publish never`，不更新正式版渠道。
- 记录安装包文件名、版本、SHA256、组件 SHA256、构建提交/工作区快照，以及以下测试项的通过和待测状态。
- 验证安装包内 Qt 插件/运行库齐全，并在隔离测试资料目录验证启动、截图、贴图、退出；说明测试包对已有安装/数据的影响后再分发。
- 使用合成测试画布或无敏感内容的窗口。请用户自愿反馈录屏/图片；默认本地日志只记录显示器数值布局，不记录截图内容。

## 请测试用户记录

- Windows 版本、两块屏幕的分辨率和缩放比例、主屏是哪块、副屏位于左/右/上/下、是否竖屏。
- 优先测试：100% + 150% 或 100% + 200%；副屏放主屏左边；再选一组上下或竖屏布局。不必为了测试安装虚拟显示驱动。

## 操作与期望

1. 鼠标分别放两块屏幕，按截图快捷键（默认 F1，可在设置中修改）。两屏均应冻结，窗口自动识别准确；Ctrl+A/F 只选鼠标所在显示器。
2. 从左屏向右屏、再反向跨接缝框选，分别复制和保存 PNG。两侧文字比例保持原始像素，接缝没有缺列、重复列、黑色条或拉伸。
3. 把窗口跨接缝放置后点击识别整窗；移动选区、八向调整、画箭头或马赛克跨接缝，复制后查看与预览是否一致。
4. 拖选靠近窗口边缘应轻微吸附。按住 Ctrl 可自由微调；松开恢复吸附；方向键移动 1 个输出像素。被前方窗口挡住的边缘不应吸附。
5. 选区在每块屏幕四角或跨屏时，工具栏和放大镜始终可见。框选结束后移动鼠标到另一屏，工具栏不跟着跳动。
6. 截图后贴图，应生成在原选区的物理位置。拖贴图跨屏、缩放、还原 100%、调整透明度、隐藏/显示后，内容仍正确，边缘光晕不侵入图片。
7. 改变缩放、拔下副屏：未完成截图应取消，重新截图可正常启动；已有贴图在剩余屏幕可操作。仅在方便时做拔插测试。
8. 托盘“禁用全部快捷键”后，截图和视图显示快捷键都不起作用；仍可从托盘截图、剪贴板贴图、显示/隐藏贴图。禁用时修改/取消录制快捷键，不应重新启用；重启后仍保持禁用。点击“开启全部快捷键”恢复，设置中应显示占用冲突（如有）。
9. 完全退出便签，快捷键、贴图和光晕均消失。重新启动后按保存的开关状态恢复。贴图右键菜单不提供鼠标穿透，托盘不提供关闭全部贴图；单张关闭、销毁与恢复最近一张照常可用。

对于错位布局导致矩形选区包含没有显示器的区域，PNG 中该区域透明属于预期。当前虚拟桌面画布上限 128 MiB（约 3355 万像素，包含空隙），超限应明确报错而不是悄悄降低画质。
