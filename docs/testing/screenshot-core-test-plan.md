## 1. 范围与执行规则

- 验收设计中的 C01—C12；明确排除项不作为缺失功能。
- 只运行截图、贴图、快捷键及确实受改动影响的附件/背景专项；不默认运行 `npm test`、`npm run test:window-frame:win` 或其他全量回归。
- 涉及公共快捷键/设置/退出流程时，补充已有相关命名测试，而不是把工作区所有原有未提交改动纳入测试。
- 真实 Electron、Qt、GPU、剪贴板、桌面和原生窗口测试从第一次运行就申请沙箱外执行。
- Node 验证显式使用 `C:\Users\Admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`，并为子进程设置不优先命中 Volta 的 PATH。
- 使用隔离的 `userData`、输出目录、快捷键和测试图；不修改用户便签、剪贴板历史或个人图片。需要临时占用系统剪贴板时应在受控验收环境执行。
- 故障注入只针对测试所启动且已核实路径/PID 的进程；不得使用进程名批量终止。
- 构建属于专项前置条件；安装包验证由单独测试包执行，始终 `--publish never`，不创建正式发布。

## 4. 用例及验收方法

### T01：快捷键注册、冲突与持久化

方法：单元测试 + 两个受控进程真实注册。

- 对三项动作分别设置、修改、清空、重启；检查配置值与运行时注册状态。
- 让另一个测试进程占用候选按键；确认保存失败、旧按键继续生效、冲突可见、托盘入口可用。
- 两项截图动作或与现有视图快捷键使用相同按键时，保存前阻止。
- 注入设置写入失败，确认不留下“配置已保存但运行时不同”的静默状态。

通过条件：每个按键只触发对应动作一次，无静默替代按键；重启状态可解释且准确。

### T02：快捷键录制和设置页生命周期

方法：设置 UI 集成 + 真实组合键。

录制期间按原截图键、贴图键和视图键；取消、保存、关闭设置页、销毁窗口并分别检查注册恢复。中文输入法组合期间不错误录入按键；配置在列表/月/周视图共享。

通过条件：录制操作不意外截图；没有悬挂的录制状态、重复监听器或被永久注销的原快捷键。

### T03：独立入口与单会话

方法：托盘/快捷键/按钮实际操作 + 协议并发测试。

在主窗口可见、托盘隐藏、灵动岛、贴边隐藏时分别启动；连续触发 10 次，并交叉调用便签/背景入口。引擎尚未就绪时重复触发；握手失败后再次尝试。

通过条件：最多一个引擎和一个活动截图会话；不先弹出主视图；迟到的结果不交给新会话；失败可重试；重复触发不提前释放贴边暂停。

### T04：冻结图像与自身排除

方法：受控测试窗口显示递增帧号、运动色块和时间戳。

触发截图后让测试窗口继续变化，等待 3 秒再选择和导出；分别启用/禁用隐藏主视图。将已有贴图放在画面中检查默认可见内容。

通过条件：预览和输出来自同一帧号；没有截图遮罩、工具栏和蓝色选区线；主视图是否入图符合设置；整个选择期间不会悄悄更新底图。保留输入画面和输出文件证据。

### T05：选区几何与边缘

方法：纯算法参数测试 + Qt 输入操作。

覆盖正向/反向拖拽、1×1 像素、极窄条、全屏、四角、八个缩放方向、移出边界、清除后重选；方向键每次移动 1 个图像像素，Shift 组合调整边界。

通过条件：显示尺寸和导出尺寸一致，无负尺寸、空裁切、重复/丢失边缘像素；不能通过越界导出另一屏内容。

### T06：像素映射和单屏 DPI

方法：生成已知物理像素位置的彩色网格/边缘标记，分别在 100%、125%、150%、175%、200% 上截图。

- 纯算法校验半开区间、非整数缩放、四边截断和无效参数。
- 真实桌面截图校验标记位置和实际导出尺寸，不能只修改 Electron 的 `deviceScaleFactor` 后声称覆盖系统 DPI。

通过条件：合成测试图裁切像素完全匹配；真实桌面稳定基准上的边缘定位不偏移。文字抗锯齿不使用跨机器整图哈希判定。

### T07：混合 DPI、负坐标和竖屏

方法：真实双屏配置，分别在每屏启动及重选；把选区拖到屏幕接缝，再跨屏移动贴图。

通过条件：截图使用实际选中屏幕；选区不会使用主屏缩放系数；单屏边界截断与设计一致；贴图跨屏后清晰可操作，重置 100% 时语义一致；没有工具栏落到其他屏幕之外。

### T08：工具栏可达性

方法：选区位于四角、四边、全屏、接近全屏高度和极小区域；设置大缩放，在纯白、纯黑、复杂壁纸背景查看并实际点击。

通过条件：复制、保存、贴图、取消始终可达；次要动作可从“更多”进入；Tab/Shift+Tab 可导航、焦点可见；没有 `top < 0` 或右侧越界。必须保存真实窗口画面，不能只测定位函数字符串。

### T09：全部标注工具及撤销重做

方法：每个工具绘制至少两个对象；检查颜色/线宽/字号，移动和调整选区后预览与导出；按完整顺序撤销到空，再重做到最后。

通过条件：矩形、椭圆、箭头、画笔、文字和马赛克均实际出现在导出图中；撤销/重做顺序正确；选区裁剪不平移或拉伸已有标注；马赛克输出像素已改变；新动作清除 redo 分支。

### T10：文字、输入法和按键优先级

方法：微软拼音输入多行中文，混合英文、数字、标点；选中文字复制/撤销；合成时按 Esc，输入结束后触发截图快捷键及工具栏输出。

通过条件：不吞字、不误触工具；第一次 Esc 不直接丢失整张截图；文字中的 Ctrl+C 复制选中文字，结束文字编辑后 Ctrl+C 才输出截图；点击输出会提交非空文字；空文字不占撤销历史。

### T11：复制后的图像有效性

方法：分别输出截图、带透明度显示的贴图和 JPEG 来源图片到剪贴板；结束截图会话、关闭贴图、退出应用后，粘贴到系统画图或其他独立测试程序。

通过条件：粘贴仍有效，尺寸和图像内容正确，无界面控件；贴图的窗口缩放/透明度不破坏其原始图像输出；其他格式的剪贴板内容不被当成成功的截图结果。

### T12：文件输出、取消和失败

方法：保存 PNG/JPEG，使用带空格/中文路径；取消文件对话框；拒绝覆盖已有文件；注入写权限拒绝、磁盘写入失败、编码失败；尝试连续点击保存。

通过条件：编码和扩展名一致；PNG 基准像素符合预期，JPEG 容许有损但尺寸/背景合成正确；取消/失败保留原图、选区和标注；已有文件不被截断；成功只生成一次结果。

### T13：输出与接管竞态

方法：延迟宿主接收；期间关闭来源表单、取消页面切换、触发退出、重复发送完成消息，或启动下一次会话后投递旧响应。

通过条件：不写入错误便签/背景；同一结果只接管一次；无来源时仍能改为复制、保存或贴图；未接管资产不提前删除，终态后不存在无引用文件。

### T14：贴图来源与独立窗口

方法：截图直接贴图；剪贴板 bitmap、PNG/JPEG/BMP/WebP 单文件分别贴图；测试空剪贴板、文字、HTML、多个文件、不支持格式、损坏/超大图像。

通过条件：支持项图像正确；不支持项给出可见反馈且无空窗；每张贴图独立；不创建便签记录；无需主窗口出现。

### T15：贴图所有操作

方法：创建 3 张不同尺寸贴图；分别拖动、滚轮/边角等比缩放、重置、调透明度、切置顶、复制、保存、关闭。隐藏/显示全部后核对每张状态。

通过条件：操作一张不改变其他图；置顶切换真实有效；透明度不低于 20%；关闭释放本图资源；隐藏保留图像和位置；取消关闭全部确认不删除任何图；确认关闭全部后窗口数归零。

### T16：退出取消、正常退出和宿主崩溃

方法：存在未保存便签草稿和 3 张贴图时退出，先取消、再确认；分别在截图中、保存对话框中退出。另开隔离实例，异常终止其宿主主进程。

通过条件：取消退出后三项快捷键、贴图、截图仍可用；确认退出后不再接受请求；优雅关闭最多等待 2 秒，随后专用 Job 回收；强杀宿主后最终在 3 秒观察窗内无引擎、贴图或遮罩残留，快捷键可被测试进程重新注册。该时间为拟定验收上限，不是已测数据。

额外验证：启动器在创建前、带 Job 属性创建期间、挂起恢复前、握手前失败的各边界均不留孤儿进程；使用 `PROC_THREAD_ATTRIBUTE_JOB_LIST` 确认进程出生即受控；Job 句柄不可被子进程继承；宿主外层 Job 限制导致创建失败时正确反馈；不结束任何其他应用的进程。

### T17：显示器变化、锁屏和睡眠

方法：截图中真实拔出副屏、改变缩放或旋转；贴图位于副屏时拔屏；真实锁屏/解锁、睡眠/唤醒。事件注入另列为补充结果。

通过条件：截图取消并恢复宿主，旧坐标不再导出；贴图被迁回可见范围且内容保留；恢复后新截图可用；没有遮罩、输入拦截和悬挂暂停计数。

### T18：主视图组合状态恢复

方法：分别在列表/月/周视图运行普通、置底、置顶三种层级，覆盖隐藏主视图开/关；另覆盖锁定、贴边隐藏、灵动岛和托盘隐藏的代表组合。

- 对 3 个视图 × 3 个层级 × 2 个隐藏设置，共 18 组分别进行成功输出与 Esc 取消。
- 对贴边隐藏、锁定、灵动岛、托盘隐藏各至少进行一次引擎异常恢复。

通过条件：恢复后的可见性、几何、锁定和层级与启动前一致；原本隐藏的主视图不被弹出；没有多余焦点抢占或贴边暂停泄漏；下一次截图和原视图快捷键可用。

### T19：资源边界与反复使用

方法：4K 基准图重复截图/取消 100 次；创建/关闭贴图 100 次；创建到数量和解码内存上限；完成 101 个标注动作；注入分配失败。

通过条件：超限有反馈且保留已有图像；无崩溃、空白成功、监听器持续累积或残留文件；撤销历史截断不改变最终图像。观察稳定后的 RSS、私有字节、GDI/USER 句柄和窗口数；句柄应回到合理基线，内存是否持续增长需结合采样分析，不能要求每次回到完全相同的 RSS。

### T20：便签附件草稿接入

方法：列表和月视图新建、已有便签编辑分别截图；保存、取消；附件达到上限后再截图；截图期间切视图或关闭编辑器；全局截图选择新建图文便签。

通过条件：成功添加的是草稿，保存便签前不改变原附件；取消不留下错误附件；超限保留截图可改为其他输出；全局操作不覆盖其他未保存草稿；关闭贴图不会使已接管的附件失效。

### T21：应用背景接入

方法：从背景设置和全局截图分别进入背景裁剪；确认/取消；注入背景存储失败；切换原生毛玻璃与背景模式后再截图。

通过条件：只有确认成功才替换背景；取消/失败保持旧背景；图像尺寸及裁剪正确；恢复主视图时无额外原生模糊层遗留；临时图片所有权和清理正确。

### T22：协议与异常隔离

方法：错误协议版本、错误握手令牌、超大消息、未知命令、重复终态、过期会话、目录外路径、虚报图像尺寸、引擎挂起/崩溃。

通过条件：拒绝非法消息而不影响便签主业务；结果不冒充成功；超时后释放本会话并恢复窗口；下一次明确触发可重启；持续启动失败不形成重启循环；诊断包含阶段和错误码，不含图片/正文/Base64。

### T23：打包、性能和长期共存

方法：在无 Qt 开发环境的 Windows 10/11 测试机安装本地测试包，确认 EXE/DLL/Qt plugins 从资源目录加载；重复正常退出、更新替换前退出、启动失败。记录首次快捷键至选区可操作、预热后响应和 PNG 输出耗时。

通过条件：没有开发机绝对路径依赖、缺失平台/图片插件、退出后的文件锁；工作区升级打包身份不被意外改变。性能应在固定设备上报告 p50/p95，首次实测后确定预算；无数据时不能标称“零延迟”或“更省内存”。

## 5. 测试分层与执行顺序

1. **纯逻辑**：C++ 几何/裁剪映射、标注命令与历史、资源上限；JS 会话状态、快捷键注册、消息校验和资产所有权。
2. **Qt 界面**：使用 QtTest 验证输入、文字 IME 配合、工具栏布局、每种标注、贴图行为。原生桌面可见性与实际剪贴板另做真实操作验证。
3. **Electron/引擎集成**：独立配置运行 T01—T03、T13、T16—T18、T20—T22；断言进程、窗口、文件和状态终态。
4. **真实视觉和设备**：T04—T12、T14—T15、T17 的关键真实场景；输出文件/截图与实际点击共同验收。
5. **资源和本地包**：T19、T23。每轮保持测试范围明确，不自动扩大到项目全量回归。

## 6. 完成门槛与未覆盖项

- C01—C12 都有实现、测试和证据；T01—T23 不得缺失结果。
