# 标签重影、图片删除与窗口激活修复

日期：2026-09-30。本记录只覆盖最新三项反馈；工作区中此前的全局 UI 修改继续保留，不计为本次新增实现。承接 [上一轮截图反馈记录](2026-09-30-ui-feedback-fixes.md)。

## 原因、修改和操作验收

| 问题 | 确认的原因与修改 | 操作验收 |
| --- | --- | --- |
| 无筛选切换到“重要”仍有重影 | 上一轮只解决副本越过滚动区的问题。旧卡片尚未淡出，保留卡片已移动进它的位置，列表内部仍会叠字；快速反向时旧动画也可能残留。现在可见离场卡片原位淡出 140ms，然后保留项补位、新项进入；取消离场错峰，后续更新、滚动、窗口缩放或卸载会清理旧动画和副本。普通刷新仍不让已有卡片重复入场。 | 准备部分带“重要”的长列表，在顶部及滚动后，反复选择、取消“重要”；再快速点两次，观察旧文字不与补位卡片重叠、不飞出列表。 |
| 删除截图向左上放大飞出 | 缩略图在四列网格内使用百分比宽度；离场时变为绝对定位，宽度改按整个图片区计算。冻结离场前的位置和尺寸，删除项只淡出；屏蔽 Vue 在居中表单高度变化时给离场项附加的 FLIP 位移。其余图片保留补位。 | 新建或编辑便签，加入横图、竖图，删除中间一张及最后一行的一张；删除项保持原尺寸淡出。表单内容减少时仍会正常重新居中。 |
| 正常层级被遮挡时显示隐藏需操作两次 | `isVisible()` 对被其他窗口盖住的窗口仍返回真，旧逻辑先隐藏，第二次才显示。现在正常层级未聚焦、隐藏或最小化时，显式恢复、置前并聚焦；已在前台时才隐藏。快捷键、托盘切换及托盘“打开主窗口”共用激活逻辑，保留用户的正常/置顶/置底设置。 | 将正常层级主窗口放到另一窗口后面，触发显示隐藏快捷键或托盘点击：一次显示并激活；在前台再触发则隐藏，随后一次恢复；最小化后同样一次恢复。 |

动画清理另修复两个关联细节：已播放完但保持最终透明度的离场动画也能取消，避免刷新失败后卡片仍不可见；辅助标题动画单独管理，避免卡片入场时把标题入场立即取消。

- `src/main/index.js`

## 测试审查与清理

- 删除 `tests/styled-select-menu.test.js`：两个测试锁定了具体 CSS 数值及 Tab 分支源码写法；下拉菜单可读性、选中呈现及真实 Teleport/Tab 行为已有组件专项覆盖，不再重复维护实现文本断言。
- `ui-feedback-app-electron.mjs`：删除无效的固定 `restart=false` 分支及无关 profile 环境覆盖，始终使用隔离资料。将单向“取消重要”扩展为选择/取消双向、顶部/滚动位置、快速反向切换；逐帧检查副本裁剪和新旧卡片重叠，并要求实际采到离场帧，避免空样本误通过。
- `ui-feedback-electron.mjs` 与夹具：加入实际 ScreenshotPicker 的 memory/draft、横竖图、中间/最后一行删除；逐帧记录相对图片区的位置与尺寸。居中弹窗随内容减少产生的整体移动，与图片自身错误飞出分别判定。另验证已完成离场可取消、辅助文字和卡片入场能同时运行。
- `view-visibility-shortcut-electron.mjs`：增加受控遮挡窗口；Windows 原生 `GetForegroundWindow` 和窗口顺序验证置前与焦点，覆盖快捷键回调、Tray 点击事件、前台隐藏、隐藏恢复、最小化恢复及托盘打开。确保没有把正常层级改成永久置顶。
- `calendar-count-preview-helper.mjs`：周视图已有最小可读画布高度，“缩小后十条必然溢出”的前提失效。改为先制造并确认真实溢出，再以实际可见条数加一形成测试数据，继续验证鼠标、键盘、预览动画和放大后的恢复，不删业务断言。
- `scripts/test-manifest.cjs`：登记此前漏列的四个 UI 验收专项，保持在 acceptance 分组，不自动扩大日常回归范围。
- 扫描测试清单及显式跳过/占位代码；没有据文件数量或仅凭源码断言形式批量删除有效业务测试。保留的列表刷新测试确实检出了本轮中途引入的“已有卡片重复入场”，修复产品逻辑后原断言通过。
