# 便签多方式提醒与稍后提醒实施方案

## 已确认的行为

- 普通便签与循环模板支持系统提醒、软件弹窗、托盘闪烁多选；不选表示关闭提醒。旧数据的开启状态迁移为仅系统提醒。
- 首次提醒沿用便签生效时间；立即生效和历史补录不创建首次提醒。模板生成的提醒属于生成实例。
- 三个入口共享一轮提醒。系统通知与软件弹窗均可设置稍后；同一便签最多有一个等待触发的任务，第一次成功保存生效，重复请求返回现有时间而不覆盖。
- 操作必须携带提醒轮次标识；已处理或旧轮次通知不能创建新任务。新一轮允许再次稍后。
- 稍后时间独立于生效时间、状态及日历区间；提供 5、10、30、60 分钟快捷项及自定义日期时间。自定义系统通知操作打开软件的时间选择界面。
- 稍后仍使用便签当前选择的所有提醒方式。任一入口设置成功后，同步撤下同轮弹窗、系统通知和该便签托盘提示。
- 软件提醒采用独立小窗，主窗口隐藏时仍能显示，不展开主窗口、不主动抢键盘焦点；多条提醒在一个窗口中展示。
- 托盘只有一个闪烁控制器，各便签独立登记/清除。点击托盘停止当前视觉闪烁；提醒处理入口和已安排的任务保留。退出清理窗口、计时器及图标。
- 编辑待开始便签可调整首次提醒；编辑进行中便签可修改方式及已有稍后任务的时间，或取消任务。普通关闭不完成便签，不产生或取消稍后任务。
- 完成、删除、关闭全部方式时取消未完成任务；恢复/重新进行不恢复旧提醒。循环模板替换旧实例时取消旧实例提醒。
- 任务持久化；重启、休眠恢复补触发过期任务一次。系统提醒受通知权限影响；软件退出期间不唤醒系统定时执行。
- 平台能力仅限制对应通道，不连带禁用软件弹窗和托盘。

## 数据与执行

1. 增加方式配置和独立提醒任务表；数据库事务与唯一约束共同保证一个等待任务及同轮仅一次稍后。
2. 生效、模板生成与提醒建档在同一业务事务中提交。发送与业务提交解耦，各通道失败隔离，保存发送状态用于恢复；不宣称操作系统投递具备严格一次性保证。
3. 统一主进程提醒服务处理调度、轮次校验、稍后、取消、窗口和通知同步；Renderer 只提交请求。
4. 独立提醒 preload 只暴露提醒能力，IPC 校验真实 sender；通知回调仅接受有效任务、动作和时间。
   Windows 通知使用四个快捷时间按钮及一个自定义时间按钮，动作复用 `abandon-note` 通知协议；运行中由单实例入口处理，冷启动请求等待提醒服务就绪后处理。系统弹窗只负责展示，稍后任务统一由软件数据库管理。
5. 保留旧 `notify_enabled` 兼容字段；不复用已被旧迁移清除的 `remind_again_at`。

## 实施顺序

1. 数据迁移、提醒事务与轮次去重；数据库专项验证。
2. 原生通知操作、独立小窗、托盘控制及应用生命周期。
3. 列表/月周新建、编辑和模板入口；提醒状态及帮助文案。
4. 相关单测、构建、真实 Electron 集成及 Windows 通知专项；整理证据和未覆盖条件。

## 局部测试章程

| 范围 | 验收 |
| --- | --- |
| 迁移 | 老库开启只迁移到系统方式，关闭保持关闭，重复启动无重复建档 |
| 事务 | 双入口连续/并发请求只有一个稍后；首次时间不被覆盖；失败回滚 |
| 轮次 | 旧通知在下一轮到时后不能创建任务；新轮可再次稍后 |
| 生命周期 | 完成/删除/关闭方式/模板替换取消；恢复不复活；重启/休眠补发 |
| 通道 | 任一通道失败不阻止其他通道；托盘创建前提醒可交接；多条不互相清除 |
| UI | 三项多选、平台禁用、时间编辑/取消、独立窗队列、键盘、窄窗、白/黑/壁纸背景 |
| 原生 | Windows 通知快捷项/自定义、冷启动回调、隐藏主窗弹出、退出释放 |

只运行直接相关测试文件和必需构建；不执行全量回归。真实 Electron/Windows 专项一开始在沙箱外运行，隔离临时用户数据，避免 Volta；测试包 `--publish never`，不发布、不提交。
