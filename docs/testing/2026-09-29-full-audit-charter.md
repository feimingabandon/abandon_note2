## 运行规则

- 显式使用缓存中的 Node 运行时并设置子进程 PATH，避免 Volta。原生 / Electron / GPU / 打包测试从开始就在沙箱外执行。
- 窗口与真实输入测试不并行；独立源码阅读可在长测试期间进行。测试运行中的源码修改须有单独复测记录。
- 测试使用临时数据库与用户目录；不操作用户便签。只在核实项目归属后处理必要的开发 / 测试进程，不按进程名批量终止。
- 当前保留默认 GPU / Chromium 安全配置；不通过关闭保护让测试通过。
- 发现代码缺陷时继续修复并验证。不得删断言或把环境失败算作通过；首次失败和复测分开保存。

- 结果分为 passed / failed / blocked / skipped / not-run。通过须同时有业务断言和最终退出码。
