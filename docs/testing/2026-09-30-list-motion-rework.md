# 便签列表动画重整与验收

日期：2026-09-30。用户确认统一重整列表动画控制逻辑。本次只调整动画、展开期间的数据保留与相关测试，不修改查询范围、排序规则、字号、颜色或截图功能。工作区已有改动保持原样。

## 改动与体验

| 操作 | 最终行为 |
| --- | --- |
| 展开、收起“更早”和标签组 | 新增共享 `ListDisclosure.vue`。真实高度配合短淡入淡出，结束后恢复自适应高度；关闭完成后才卸载内部卡片。中途反向读取当前呈现高度，不重新从零播放。 |
| 首次加载和慢查询 | 等数据可用再展开内容，等待期间显示加载提示。标签组等待中也可取消展开；旧查询完成不会反转最后的关闭意图。 |
| “更早”关闭后重新打开 | 关闭途中反向复用现有内容；完全关闭后仍按原规则重新加载首批 10 条，后续每批追加 20 条。 |
| 筛选、新建、删除与补位 | 保留退出先淡出、保留项再补位的时序。卡片淡入约 200ms、位移 4px，错峰延迟上限由 360ms 收紧至 64ms；补位约 260ms，快速更新保留当前透明度，不跳到另一状态。 |
| 滚动、尺寸变化 | 滚动只移除脱离容器的退出副本，保留普通入场；窗口尺寸变化清理退出副本与旧布局补位，不统一取消全部动画。零尺寸元素不再视为可见。 |
| 分组与卡片动画交接 | 高度展开/收回期间，内部卡片不同时播放差分入场或补位，避免两套动画争夺位置。 |
| 加载更多 | 时间线、自定义分页沿用局部差分；标签组分页也接入同一控制器。已存在的卡片不重播入场。 |
| 初次打开、主动刷新及模式切换 | 首次加载补齐可见内容入场；主动刷新和模式切换使用短离场、统一入场。快速选择排列模式只保留最后一个待处理目标，避免后续点击被忽略。 |
| 工具栏筛选面板 | 移除依赖 `transitionend` 的临时高度监听，改为可取消的 Web Animations 生命周期；面板仍按 out-in 交换，时长与分组开合一致。 |

可直接体验：将“更早”收起后展开，再在收起一半时点击展开；对标签组重复相同动作。随后滚动列表并新增便签、选择/取消“重要”、加载更多，以及快速切换“自定义 → 时间线”。应看到明确但短促的反馈，没有整列反复重播或被滚动截断。
