# 截图与贴图 UI、交互修改方案

日期：2026-10-12。用户已授权按评估方案实施。产品仍只支持 Windows 10/11 x64；苹果风格用于视觉与交互设计，项目 UI 标准为实施依据。

后续用户否定了本版工具菜单与参数浮层的可用性。工具栏部分已由 [Snipaste 结构重做方案](2026-10-12-capture-snipaste-toolbar-rework.md) 替代；本页保留早先的设计记录，不能用它判断当前工具栏应有的行为。

## 目标与范围

将截图编辑器从密集的两行工具面板改为克制的主工具栏与按需参数浮层。截图、来源页面截图和贴图共用工具分组、图标、参数、键盘及焦点规则。保留上一轮连续马赛克、圆形擦除、准确命中、裁剪像素一致和撤销重做行为。

1. 移除公开的折线工具。形状分组提供矩形、椭圆；线条分组提供直线、箭头；画笔分组提供画笔、荧光笔。按钮本体使用本次编辑器内上次选择的子工具，箭头展开选项；选中状态、提示和无障碍名称同步。文字、马赛克、橡皮擦保留独立入口。
2. 主工具栏默认单行，保留选择、工具、参数、撤销/重做及输出操作。窄空间时保证完成、取消和更多操作可达。主完成动作改为紧凑强调按钮，图标常态透明；共享稳定表面、弱轮廓和统一矢量图标。输入控件使用主题派生的边线，键盘焦点为克制的中性提示。
3. 参数不常驻第二行。通过参数按钮打开当前工具的锚点浮层，颜色、笔刷/线宽/字号、马赛克方式与颗粒、文字字体与旋转按工具呈现。字段名称清晰；保留多字符输入焦点与参数独立记忆。
4. 子菜单与参数浮层支持键盘导航、Escape 先关闭最内层、焦点恢复、点击外部关闭且不穿透绘图、再次触发收起。菜单保留 Qt 原生交互；参数浮层限制在当前屏幕内并避让边缘，使用短淡入与轻微位移，快速反向操作从当前状态继续。结束截图、隐藏工具栏或关闭贴图时一并清理浮层。
5. 新增“快速截图复制”，默认 Ctrl+F1，可修改并遵守现有快捷键总开关、占用提示和录制期间暂停规则。F1 保留正常截图编辑。快速模式框选松开后复制图像并退出，不展示标注工具栏；点击识别出的窗口/控件也可复制。Esc 取消。剪贴板失败时保留选区、显示原因，可用 Enter/Ctrl+C 重试。不会覆盖已有正在进行的截图模式。
6. 托盘“查看便签提醒”改为“待处理提醒（数量）”，零条禁用，归入便签相关区域。数量来自当前有效的已到期提醒，状态变化时更新；继续允许重新打开已收起的提醒。新增快速截图复制入口。提醒数据库与处理语义不变。

## 实施与验证

先保存任务开始时的文件快照，保留现有未提交工作。分步修改快捷键/快速模式、托盘提醒、原生共享编辑器与浮层；同步帮助说明。

- Vitest 仅运行截图快捷键、协调器、设置 schema/写入、托盘控制器、提醒服务及实际改动直接相关的文件。
- Qt 使用显式选择的截图 UI、UX、参数及选区专项，验证工具分组、菜单/参数焦点、外部点击、边缘定位、绘制连续性、快速复制和复制失败恢复；按需要保留核心图像专项。
- Windows Qt 构建和真实 Electron/原生窗口专项一开始在沙箱外执行；Node 显式使用 Codex 缓存运行时并设置子进程 PATH。工作区部署与构建产物哈希一致。
- 使用纯白、纯黑、复杂底图和窄选区的合成证据做视觉检查。记录实际执行的业务断言；不把 offscreen 或合成坐标验证当成真实混合 DPI/多屏验收。
