# Windows 成熟度整改验收记录

日期：2026-09-09。原有代码回滚基线：`5333e402b4fd6ff4e0747174b44a556dcafd0194`。实施范围见 [最终整改计划](WINDOWS_MATURITY_PLAN.md)。

## 已实现

1. **编辑内容保护**：新建、完整编辑、快速编辑、循环模板、日历新建和按日期快速草稿接入共享暂存。切换视图、托盘切换与退出共用检查；正在提交或暂存失败时阻止页面导航。继续操作保留草稿，重新打开对应编辑器恢复表单，不自动写入业务数据库。设置支持导出草稿。
2. **快速编辑冲突**：提交时比较打开时的正文；有其他修改时保留两份内容，提供复制草稿、重试保存和明确放弃后加载最新正文。
3. **普通便签恢复**：搜索结果的“操作 → 恢复便签”接通数据库和广播；正文、标签、附件保留；提醒关闭；过期预约转为进行中，完成状态保留；不自动重建已关闭的桌面便利贴。永久删除仍有危险确认。帮助文案同步。
4. **故障恢复**：主渲染进程 60 秒内至多自动重载两次，之后提供手动重载、重启、打开诊断日志；无响应时提供等待或重载。启动失败显示明确错误。核心激活任务指数退避，最长 15 分钟，设置可主动重试。
5. **共享交互**：搜索、快捷键录制、日历快速创建使用 IME 防误提交判断；通用选择器与标签浮层按视口翻转、限宽限高；方向键、Escape、Tab 和焦点恢复覆盖浮层；模态识别归属于自己的 Teleport。搜索结果增加可聚焦操作按钮。
6. **信息与视觉**：状态显示“待开始”；设置搜索按现有分区定位，公共设置有范围说明；主按钮前景色与背景配对；状态色、焦点环、滚动条和选择器动效使用共享令牌。首次作者故事、赞赏及其按钮保持原样。
7. **容量与性能**：标签/附件关联查询每批 500 个 ID；日历先过滤再补全关联数据；日报不加载无用关联字段。缩略图串行解码、请求去重及 16 MiB / 128 项缓存，按路径、时间、大小、目标尺寸失效。帮助、模板、设置按需加载。
8. **工程组织**：Vitest 限定正式 tests；忽略本地临时审查副本和原生编译产物；新增草稿协议、恢复、浮层定位、设置搜索及缓存独立模块，避免继续集中到主入口。没有一次性重写整个主进程或列表。

## 性能证据与决定

本机内存数据库、合成中文文本：5万记录关联查询约 62ms，前 50 条子串搜索约 13ms；不是实际用户磁盘数据库或所有搜索分布的性能承诺。保留 LIKE 与现有分页，暂不引入 FTS/中文分词重写。

1600×1200 合成图片重复读取 100 次：缓存前约 552ms，缓存后最终约 16ms。首次单图解码仍使用 Electron nativeImage，极大图片解码仍可能短时阻塞主进程；队列在每次解码之间让出事件循环。

共享 renderer JS 输出由约 1.37MB 降为 0.95MB，设置/模板/帮助成为独立分块。这里只证明首屏静态依赖减少，没有宣称实际冷启动耗时同比下降。
