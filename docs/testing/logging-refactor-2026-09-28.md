## 测试中修复的问题

1. contextBridge 策略回调错误返回 WeakMap，导致页面对象无法克隆；改为无返回值。
2. 主窗口固定 32 KiB 运输额度使短时业务突发丢弃部分轨迹；调整为主窗口最多 256 KiB，其余通常 32 KiB，总额度仍不超过 1 MiB。
3. 文件冻结发生在保存对话框之后；改为点击后的提交屏障完成时固定偏移，租约过期明确失败，不导出混合快照。
4. 测试本身在 Electron ready 前顶层等待、等待已经销毁的便利贴页面返回，曾导致专项挂起；调整测试生命周期后最终退出码为 0。早期中止不计为通过。

## 审查后修复验证

本节对应同日审查发现的五项问题，修复前基线保存在 `tmp/logging-review-fix-baseline/`，没有将工作区其他修改计入本次修复范围。

1. 关闭便利贴和切换主视图前限时提交待发送记录，页面卸载尽力补交；保留已结束 producer 的最终确认或缺失状态。强制销毁、重新加载及超过 64 个历史 producer 时不再静默忽略缺失。正常退出在销毁窗口前执行一次页面收集。
2. 搜索输入只管理搜索防抖；模式倒计时和策略订阅在弹窗关闭或卸载时清理。输入搜索后，倒计时和外部模式变更仍能更新。
3. 存储目录初始化失败后，后续操作重新尝试；移走同名阻挡文件后，同一个 store 实例可继续写入和查询。
4. 保留空间冲突时使相关导出失效并释放文件；覆盖保存对话框等待和正在导出两种时机，新写入继续，已有导出目标保留，临时输出清理。
5. 查询按事件时间跨池排序，覆盖延迟回放、相同时间、Unicode 字节偏移、无末尾换行、页面字节上限以及追加期间的稳定分页。
