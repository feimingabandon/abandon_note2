# UI 材质与边线开发标准

本标准适用于 `src/renderer` 内的主窗口、月视图、设置页、弹窗、浮层和桌面便签组件。新增或修改 UI 时必须优先复用 `src/renderer/src/assets/tokens.css` 中的语义令牌，不得在组件内重新发明一套中性灰色。

## 1. 核心原则

1. 表面色和边线色职责分离：常态表面从 `--bg-color` 派生，中性边线从 `--text-color` 派生。
2. 避免“灰底 + 灰边”同时突出。一个组件在常态下应主要依靠表面或边线表达层级，不能让两者争抢注意力。
3. 内容层保持克制；材质重点用于控件、导航和浮层。不要在玻璃表面内部反复嵌套玻璃。
4. 所有组件细线固定使用 `1px`，不得用 `rem` 绘制发丝边线，避免字号变化造成亚像素模糊。
5. 蓝色焦点、红色危险、绿色成功和便签状态色属于语义色，不纳入中性边线替换。
6. 每次视觉调整都必须检查复杂壁纸、纯白背景和纯黑背景。
7. 普通悬停一次只强化一个主要视觉通道：文字、边线、填充或阴影只能择其一为主，不得把灰底、深边线和浮起阴影同时叠加。
8. 项目内所有动画均由应用自身的动效规范控制，不得读取、使用或遵循系统 `prefers-reduced-motion`（“减少动态效果”）媒体查询，也不得因系统级动效偏好静默取消、缩短或替换项目动画。
9. 普通可点击按钮必须具备点击反馈，默认使用约 `0.98` 的全局轻微缩放按压；带下拉菜单、选择面板、日期或时间面板的触发器不使用按压缩放，面板展开与收起本身就是反馈。操作结果已经由内容区域清楚表达时，按钮不得重复播放方向位移或跳动，例如月份箭头只保留按压反馈、回到今天由目标日期格反馈。只有持续动作或控件状态本身需要说明时才使用语义动画，例如刷新图标在刷新期间旋转、展开按钮同步旋转指示图标。不得给所有按钮机械套用同一种夸张动画。

## 2. 全局令牌

| 令牌                         | 用途                               |
| ---------------------------- | ---------------------------------- |
| `--ui-border-divider`        | 导航分隔、区域分隔、卡片弱边线     |
| `--ui-border-control`        | 输入框、选择器等普通控件轮廓       |
| `--ui-border-hover`          | 输入控件和小型胶囊的悬停轮廓       |
| `--ui-surface-subtle`        | 分组容器、弱内容表面               |
| `--ui-surface-control`       | 输入框、选择器等常态控件表面       |
| `--ui-surface-control-hover` | 需要填充反馈的普通按钮悬停表面     |
| `--ui-fill-passive`          | 无边线胶囊、弱状态标识             |
| `--ui-fill-hover`            | 图标按钮、菜单选项的小面积悬停反馈 |
| `--ui-fill-pressed`          | 选中、按下或需要更明确的无边线填充 |
| `--ui-accent`                | 选中、焦点等蓝色交互语义           |
| `--ui-accent-subtle`         | 蓝色交互语义的弱填充               |
| `--ui-warning`               | 需要用户注意但不阻断操作的提示     |
| `--surface-panel`            | 滑入式功能面板                     |
| `--surface-modal`            | 编辑器、确认框等模态内容表面       |
| `--surface-modal-scrim`      | 模态内容背后的统一遮罩             |
| `--surface-float`            | 下拉菜单、日期选择器等高频浮层     |

禁止重新使用已经废弃的 `--ui-fill-control`、`--ui-fill-subtle`，也禁止用固定的 `rgba(128, 128, 128, …)` 作为普通组件常态背景。

### 层级令牌

层级分为两套顺序，数字只表达同一套体系内的先后关系。局部层级不能和全局层级直接比较。

| 顺序 | 局部令牌            | 用途                           | 当前代表实现                       |
| ---- | ------------------- | ------------------------------ | ---------------------------------- |
| 0    | `--z-local-base`    | 背景、轨道、选中指示底层       | 窗口壁纸、操作栏轨道、频率选择底层 |
| 1    | `--z-local-content` | 普通正文、图像、当前视图       | `.app-scene`、卡片正文、图像内容   |
| 2    | `--z-local-raised`  | 局部按钮、状态环、加载遮罩     | `StatusRing`、帮助编号、局部加载态 |
| 3    | `--z-local-overlay` | 卡片状态覆盖、局部选择面板     | 完成态覆盖、月历事件条、年月面板   |
| 4    | `--z-local-top`     | 拖拽手柄、组件内菜单、局部导航 | 窗口手柄、排列菜单、月历工具栏     |

| 顺序 | 全局令牌               | 用途                                     | 当前代表实现                                    |
| ---- | ---------------------- | ---------------------------------------- | ----------------------------------------------- |
| 1    | `--z-global-presence`  | 脱离列表的进退场动画副本                 | `useNotePresenceMotion` 的便签克隆              |
| 2    | `--z-global-panel`     | 设置等窗口级滑入面板                     | `SettingsPanel`                                 |
| 3    | `--z-global-workspace` | 循环模板、帮助等整页工作区               | `TemplatePage`、`HelpPage` 外层                 |
| 4    | `--z-global-editor`    | 便签、模板和月视图业务编辑器             | 便签编辑器、模板编辑器、月视图编辑器            |
| 5    | `--z-global-modal`     | 标签管理、更新、日志、软件通知等应用模态 | `AppModalShell` 及其所有业务弹窗                |
| 6    | `--z-global-popover`   | 下拉框、菜单、日期时间选择器和 Tooltip   | `TagSelector`、`StyledSelect`、时间选择器、菜单 |
| 7    | `--z-global-preview`   | 图片大图预览                             | `ImagePreview`                                  |
| 8    | `--z-global-confirm`   | 必须盖住当前操作面的确认对话框           | `ConfirmDialog`                                 |
| 9    | `--z-global-toast`     | 应用级结果和错误消息                     | `MessageToast`                                  |
| 10   | `--z-global-critical`  | 必须独占窗口的临界工作区                 | `WallpaperCropEditor`                           |

- 普通组件内部只能使用 `--z-local-*`；整页工作区、窗口级功能根壳、`Teleport to="body"` 的浮层和挂到 `body` 的动画副本使用 `--z-global-*`。窗口级根壳即使仍位于 `.app-scene` 内，也按其窗口语义选用全局令牌，但它仍受父级层叠上下文约束。
- 禁止在组件中新增 `80`、`9998`、`30000` 等任意层级数字，也不得通过不断增大数字修复遮挡问题。需要新语义时先更新本表和全局令牌。
- 全局浮层的 DOM 根节点必须直接使用对应令牌。`AppModalShell` 默认属于 `--z-global-modal`；确需覆盖时只能传入另一项全局层级令牌，不能传裸数字。
- `transform`、`filter`、`opacity`、`isolation` 等属性可能创建新层叠上下文。排查遮挡时先确认两个元素是否处于同一上下文，再比较层级令牌。
- 列表进退场副本固定处于 `--z-global-presence`，必须低于下拉菜单和其他交互浮层，避免动画内容穿过面板。

## 3. 组件搭配规则

### 输入框、下拉框、数字控件

- 常态：`--ui-surface-control` + `--ui-border-control`。
- 悬停：保持 `--ui-surface-control` 不变，只将边线提高到 `--ui-border-hover`；箭头或辅助图标可以同步提高透明度。
- 聚焦：使用强调色边线或聚焦环，不额外叠加一层灰色表面。
- 内部按钮只使用分隔线，不允许在外轮廓内再套完整轮廓。
- 带下拉菜单、选择面板、日期或时间面板的触发器必须使用 `aria-haspopup` 声明面板语义，并由全局样式取消按压缩放；不得在组件内重新添加点击位移或缩放。面板的展开、收起与箭头状态承担操作反馈，面板内部的选项及确认操作仍使用普通按钮反馈。
- `StyledSelect`、`FontSizeInput` 一类自定义选择器使用自上而下裁剪揭示的 `dropdown` 动画；收起时反向卷回，不得让整个面板及内容瞬间同时显隐。

### 图标按钮

- 常态无边线、透明背景。
- 悬停使用 `--ui-fill-hover`。
- `--ui-fill-hover` 只用于紧凑点击区域，不得扩展成整行、整张卡片或不可见热区的灰色遮罩。
- 选中可使用 `--ui-fill-pressed` 或语义色填充。

### 胶囊、标签和分段控件

- 单个胶囊采用填充式表达，常态不加中性边线。
- 一组相关按钮可以共享一个 `--ui-surface-subtle` 分组背景。
- 组内按钮常态透明，悬停和选中只改变当前按钮。
- 已有轮廓的胶囊悬停时优先只增强边线和文字；无边线胶囊才使用 `--ui-fill-hover`。
- 紧凑图标组已有共享背景时，若图标颜色或透明度足以表达选中状态，选中按钮继续保持透明；只有辨识度不足时才使用 `--ui-fill-pressed`。

### 卡片和日期格

- 内容卡片只保留弱表面和弱边线；悬停时保持背景不变，只将边线从 `--ui-border-divider` 提高到 `--ui-border-control`。
- 普通卡片和设置整行悬停不得增加灰色遮罩、浮起阴影或背景透明度；阴影只保留给拖拽对象、图片预览等确实需要空间层级的对象。
- 月历日期格常态透明，不为 42 个格子分别添加灰色填充。
- 月历日期格悬停时继续保持透明，只将边线从 `--ui-border-divider` 提高到 `--ui-border-control`；不得同时增加灰底或浮起阴影。
- 月历中的今天不改变左侧日期数字；在日期格顶部栏右侧使用蓝底白字的圆形“今”徽标。
- 月历日期格顶部使用不增加头部高度的紧凑单行：公历日号在左，农历短文字在中间，徽标区在右，以免牺牲便签横条容量。顶部按“公历日号与状态徽标固定、农历或节日文字弹性收缩”的优先级布局；侧栏展开或日期格变窄时，节日文字必须单行省略并通过悬停标题保留完整信息，“休 / 班 / 今”不得被长文字挤压、换行或裁掉，极窄日期格可以同步收紧固定槽尺寸和间距。农历短文字与公历日号使用相同字号；普通日期显示农历日，初一显示农历月。月历节日数据覆盖常见中国传统节日、国家年节及纪念日、行业节日，以及日期规则稳定的常见现代节日；同日存在多个节日时，月格最多并列两个紧凑简称，悬停标题保留全部名称。全体公民可放假的法定节日使用与“休”徽标一致的绿色文字，其他传统、现代、纪念及行业节日统一使用蓝色文字，普通农历日期继续使用默认文字颜色；不得根据节日恰好落在周末或调休区间而改变其法定颜色分类。节日优先于二十四节气，二十四节气优先于普通农历日；二十四节气使用蓝色文字。法定休息日使用紧凑的绿色“休”徽标，调班工作日使用紧凑的橙色“班”徽标，并与“今”徽标共享右侧徽标区。未来增加天气时，天气只能作为可降级辅助信息，不得进入或挤占状态徽标固定槽：宽日期格可以显示图标与温度，变窄后依次降级为仅图标、日期格内隐藏，并在当日侧栏中保留完整天气。某年份没有通过校验的节假日数据时必须静默隐藏“休 / 班”，不得留下空徽标、错误占位或阻断月历、农历及便签功能；应用跨公历年持续运行时必须自动重新检查新年度数据，不得要求重启后才发现缺失。
- 日期格底部采用三段式信息栏：左下角放新建按钮，中间只在存在未渲染横条时显示三个清晰的中性实心点，右下角用中性圆角长方形显示当天便签总数且只显示数字。三个点悬停日期格时只增强颜色、透明度和尺寸，不增加背景或独立点击逻辑；点击后继续由日期格统一展开或收起当日列表。不得使用加号或蓝色表达溢出。
- 月历月份导航采用“上个月—年月标题—下个月”的居中流式组合，并以当前日历内容区域为居中参照；日期侧栏展开时应随剩余日历区域自然移动，不得用相对整个窗口的绝对定位固定标题。年月标题本身是选择入口，点击后使用统一浮层材质和 `dropdown` 卷轴动效展开年份、月份选择；修改年份或月份只驱动下方月历切换，面板必须保持展开。面板只能通过再次点击年月标题或点击面板外透明遮罩收起；遮罩必须完整拦截该次指针事件，禁止穿透并误触日期格、便签或新建按钮。工具栏右侧只保留“今天”和刷新操作，不再常驻显示年月输入控件。
- 月视图的自定义窗口标题栏不重复显示“月视图”文字；当前年月已由日历工具栏承担页面标题语义。
- 月视图新建器应优先复用列表新建面板的共享表单组件。图片区域统一使用 `ScreenshotPicker`，同时提供截图、点击选择、拖拽添加、缩略图和大图预览；帮助浮层必须高于模态和滑入面板层级。
- 月视图日期侧栏必须复用便签列表的 `NoteCard`，保留状态圆环、正文展开、标签、附件、复制、修改、置顶、贴到桌面和删除能力，但不启用拖拽排序。共享卡片的元信息固定为单行：状态和右侧标签、操作图标优先保留，中间的生效及完成时间使用弹性空间，卡片宽度不足时整段单行省略并通过悬停标题提供完整内容，不得自动折为第二行。侧栏排序与日期格横条共享稳定规则：持续天数降序、同持续天数内置顶优先、生效时间升序、ID 升序；普通便签按一天参与持续天数比较，因此普通便签之间仍由置顶优先。切换日期时侧栏外壳保持固定，跨日仍存在的卡片使用 FLIP 平滑补位，离开与进入的卡片按日期方向进退场；天气区域在有无之间平滑展开或收起，有天气的日期之间只替换内容，不得瞬间顶动便签列表。快速连续切换必须取消前一轮进退场，避免动画排队。
- 列表新建便签保持“立即生效”空值；首次打开生效时间面板时，选中日期的时间草稿默认使用 `00:01`。月视图在今天新建时继续保持“未调整时间即立即生效”的逻辑，只有在未来日期新建时才把生效时间默认设为该日 `00:01`。这些默认值不得影响编辑已有便签，也不得覆盖用户已经手动选择的时间。
- 当前月份日期格采用面板切换交互：首次点击展开当日列表，再次点击同一日期收起列表；点击其他日期时保持列表展开并切换内容。
- 月份切换必须按时间方向驱动整块日历内容：目标月份更晚时旧内容向左退出、新内容从右进入；更早时反向，位移使用日历宽度比例以确保不同窗口尺寸下都清晰可见。目标年月未变化时不得复用整月换页动画：重复选择当前年月只关闭选择面板，不请求或移动日历；“今天”仍在当前月时只更新选中日期并轻触目标日期格；手动刷新以及便签创建、编辑、删除、定时状态转换等广播同步都保持日期格框架固定，旧便签横条、数量和溢出提示先在约 `220ms` 内降至半透明并轻微失焦，交换数据后再用约 `380ms` 恢复至清晰，不得完全消失、移动日期格或在数据替换后制造从空白闪现的效果。后续加载保留旧内容直至新数据就绪，加载遮罩只用于首次无数据状态，避免白色闪烁。月历方向切换属于核心状态反馈，不得被系统媒体查询静默取消；自动化测试必须验证关键帧实际启动，而不只验证最终年月结果。
- 月历标题中的年份、月份发生变化时，数值必须按时间方向上下滚动：更晚向上滚，更早向下滚。年份固定预留四位数字槽，月份固定预留两位数字槽，使 9 月与 10 月共享同一标题宽度；不得在 Vue 新旧数字同时过渡期间改变数值槽或标题宽度，避免裁切、挤压和箭头位移。刷新按钮在刷新期间保留旋转反馈；今天按钮和左右月份箭头只使用约 `0.98` 的轻微按压，由目标日期格及整月内容切换表达操作结果，不再额外跳动或位移。年月标题点击使用克制的按压反馈。
- 选中、今天和状态信息使用各自语义色。

### 面板、弹窗和浮层

- 普通滑入面板使用 `--surface-panel`。
- 月视图左侧日期列表与窗口左边缘贴合，面向日历的右上角、右下角使用设置项对应的 `--window-radius`，不得硬编码局部圆角值。
- 循环模板、帮助页等覆盖内容区的整页滑入面板，外壳必须使用 `var(--window-radius)`，内部面板和页面根节点使用 `inherit` 并开启裁剪；不得让局部页面回退为直角。
- 模态编辑器和确认框使用 `--surface-modal`，并配合 `--surface-modal-scrim`。
- 模态打开时必须把焦点移入内容区，`Tab` / `Shift+Tab` 只能在当前模态内循环；支持 `Escape` 请求关闭，并在关闭后把焦点恢复到原触发控件。禁止只设置 `aria-modal` 和底层 `inert`，却把键盘焦点留在底层界面。
- 下拉菜单和日期浮层使用 `--surface-float`，保证文字不被壁纸污染。
- 模态内容内部的控件仍遵循普通控件规则，不再创建新的玻璃层。

### 开关

- 关闭轨道使用中性填充，开启轨道使用主题强调色。
- 滑块始终为 `2px` 空心白色圆环，并使用轻微阴影保持其在纯白和纯黑背景上的轮廓。

## 4. 明暗与壁纸适配

- 纯白背景：背景色表面自然融入，主要由文字色边线建立轮廓。
- 纯黑背景：背景色表面同样融入，由浅色文字派生边线建立轮廓。
- 复杂壁纸：面板和弹窗先形成稳定表面，内部控件不能直接承受壁纸颜色。
- 不根据某一张壁纸硬编码白色或黑色控件背景；背景与文字设置变化后，语义令牌必须自动跟随。
