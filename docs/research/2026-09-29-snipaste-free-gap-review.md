# Snipaste 免费版核心体验差距复核

日期：2026-09-29。范围：独立评估当前工作区的截图/贴图实现，不修改产品代码。

## 结论

当前实现已打通全局入口、原生截图、标注输出、贴图以及便签/背景交付，但不能据此认定达到 Snipaste 免费版的核心交互体验。明显差距集中在操作栏反馈、选区操作、当前标注的编辑过程、鼠标/键盘语义和贴图操作。

上一轮把六种工具能绘制、输出可交付、进程能回收作为主要完成证据，对用户实际操作的连续性覆盖不足。原方案还提前排除了部分与核心体验直接相关的能力；这些排除项属于设计取舍，不能作为已经达到对标体验的证据。

## 取证范围和限制

- 对标依据为 Snipaste 2 官方免费版/专业版对照表、基础操作、内置快捷键、高级技巧和更新日志。取证时公开更新日志顶部为 v2.11.3；未据此断言这是所有渠道的最新二进制版本。
- 当前产品依据：原生源码、已有合成白底工具栏截图，以及本轮离屏 Qt 行为探针。探针直接链接当前构建的 `capture_ui.lib` / `capture_core.lib`，只创建合成画布，不抓取桌面或读取剪贴板。
- 本机应用清单及常用软件/下载目录未发现 Snipaste；没有进行 Snipaste 可执行程序的并排实操。文档未明确的外观、动画、光标细节不冒充实机结论。
- 内置浏览器两次超时后，改为只读获取官方站点的 Markdown 内容。当前便签窗口的截图/文本读取被自动审批拒绝，理由是可能包含私人便签；未继续读取，改用合成画布和代码。
- 本轮不是修复或完整验收：没有运行全量回归，没有改写原范围或新增产品功能。

## 二、原方案排除了，但属于免费版的能力

这些不是这一轮擅自追加的实现任务，应在重定核心范围时重新取舍。不能用“高级功能”这一统称掩盖它们对日常使用的影响。

| 能力 | 当前状态 | 重新评估意见 | 官方依据 |
| --- | --- | --- | --- |
| 窗口/界面元素自动检测，Tab 切换检测类型 | 无，只能手工框选 | 对快速截取窗口、按钮很有价值，建议纳入核心体验 | S1/S3 |
| 放大镜、像素取色与光标微调 | 无 | 放大镜直接帮助精确框选，优先级应高于 OCR 等扩展能力 | S2/S3 |
| 上次截图区域、成功截图历史、快捷保存/自动保存 | 无 | 上次区域和快捷保存适合重复操作；历史与自动保存可后续评估存储策略 | S1/S2/S3 |
| 贴图旋转/镜像、固定缩略图、Shift 拖动吸附对齐 | 无 | 服务于并排参考和整理贴图，属于贴图体验，不依赖跨重启恢复 | S1/S2/S4 |
| 剪贴板文字/HTML/颜色转图、贴图内容替换 | 当前只接收图像或单个受支持的图片文件 | 可根据便签产品需求决定范围，不应说免费版只支持图片 | S1/S2/S3 |
| 鼠标穿透、贴图分组、白板、延时截图、自定义预设尺寸 | 无 | 仍可延后；需明确是产品取舍，并保持本应用退出即回收的约束 | S1/S2 |

## 三、不能误算为免费版缺口的功能

依据 S1，以下是专业版能力，不应拿它们证明本次“免费版对标”未完成：

- 直接点选任意已完成标注进行二次编辑、自由选中、序号标注、双向/更多箭头样式。
- OCR、识别二维码/条形码、刷新截图。
- 进入截图后直接输入尺寸、固定截图长宽比；免费版“开始截图前自定义尺寸”是不同功能。
- 各工具分别记忆颜色、自定义调色板；不要和全局参数保持混为一谈。
- 贴图裁剪、多选、灰度/反色、Solo、直接输入缩放比例。
- 任意功能自定义全局快捷键和指定程序忽略快捷键。

当前已经提供的“单张贴图取消/恢复置顶”，在官方对照表反而属于专业版。说明上一轮能力取舍并没有完全按免费版的日常操作优先级排列。

“贴图上新增标注”与“直接选择旧标注二次编辑”也必须区分，前者不能因为后者收费就被一并排除。

## 四、下一轮应如何验收

建议先校正交互模型，再扩充工具数量；以下是评估建议，不代表已经实现或已获授权开始重构。

1. **完成截图与反馈**：选区双击、中键、工具选中态、光标、工具条显示/隐藏、常用参数就地可改。验证同一条用户动作序列，不只调用 output 回调。
2. **选区与标注状态**：空格移动、Ctrl/Shift 微调、Shift 约束图形；明确“当前可编辑标注、已提交标注、历史重做”三种状态。文字右键结束必须保留内容。
3. **贴图操作**：贴图能继续标注；Ctrl+滚轮、中键、加减/方向键、保存/关闭和关闭恢复形成一致行为，区分关闭与销毁。
4. **免费版基础工具**：补齐直线/折线、记号笔、模糊、橡皮擦，且颜色/粗细等参数确实作用于所选工具。
5. **高频效率功能取舍**：自动框选、放大镜、上次区域、快捷保存优先评估；历史、分组等单列，继续遵守与便签同生共死的约束。

新的验收必须包括：动作后界面反馈、修改当前对象的结果、最终输出像素、重复操作成本、快捷键语义和错误恢复。已有 29 项 Qt UI 结果可以证明覆盖过的行为正确，不能替代 Snipaste 交互对标；例如旧 `selectionAndExport` 本来就把“双击等于全屏”写成了预期。
